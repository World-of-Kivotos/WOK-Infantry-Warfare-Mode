# WOK步战 2026-09-06 更新说明

本次归档 25 项 MOD 新增功能组、3 项配套工具与已有功能修正，同时统一各模块源码版本、当前说明和构建文件。功能分组依据为本地 `6944d76` 之后的变化，完整证据见 [内容与版本审计](CONTENT_VERSION_AUDIT_2026-09-06.md)。这是开发/测试源码更新，仍有下文注明的游戏内联动验收待完成。

Git 内容提交为 `6c6fccf3`（302 个文件）。递交时发现远程 `codex/体力` 的 7 个分拆提交与本地汇总提交分叉，因此采用合并保留双方历史；远程旧测试目录、旧版本规则与陈旧协议断言以当前明确规则和已验证实现为准，并保留其早期测试说明与历史记录。本次递交目标为 `codex/体力`，不创建正式 Release 或改写远程提交历史。

## 新增

- **阵营与配装导入导出**：管理员可将全部阵营、编制、兵种、装备槽位、装备池、白名单、载具规则、完整 NBT 与弹药上限导出为一个 JSON 包；支持文件浏览、导入预览、确认、自动备份、异常回滚及启动恢复。
- **补给与部署**：车辆运输大/中型补给并持久化余量；新增 500 点中型弹药箱、大型补给站燃烧爆炸流程、小队队包与持久冷却；每战局首次部署免费发放逐枪上限的备用弹药。
- **阵营编制与武器属性**：新增凯撒 234机械化作战单元、研讨会骑兵军团，支持逐枪伤害、穿甲与射速倍率。
- **指挥官支援**：新增侦察卫星、千禧年 F-15EX JDAM 1000 磅空袭、F-16C GBU-12 500 磅激光制导空袭；核心提供临时情报、单项冷却清除、攻击范围与在途显示。
- **占点附属**：管理员圈地与据点管理、顺序解锁、连续控制及争夺算法、世界存档、独立 HUD 和可选核心地图显示。
- **倒地救援附属**：致死转倒地、失血/补枪、队友救援、伤员拖行与医疗软联动。
- **载具平衡**：按种类划分 T1/T2/T3 车体与部件模板，增加方向装甲与步兵反坦克伤害归一化。
- **配套工具**：离线编制配装编辑器、枪械/护甲平衡配置应用、M249 姿态后坐力试调；增加源码/文档/JAR 内部版本核对工具。

## 修改

- 普通玩家继续只能从管理员规定的装备中选择，不开放个人自定义配装。
- 地图统一清晰的物理字号、图层次序和友军图标尺寸，沿用现有战术平板组件与状态色。
- 部位伤害默认换算由 10 调为 8；轻甲移速由 +10% 调为 0%，中甲由 0% 调为 -5%，重甲保持 -12%。
- 载具观瞄完整自愈约 20 秒改为约 100 秒；炮塔受损转速倍率由 0.25 调为 0.45；M3A3 车体为 440。
- 为此前已提交但漏升版本的黄针共享慢回、延迟副作用和部位 HUD 调整补齐版本归属。
- 每次交付新增游戏内容或改变已有内容都更新所属模块版本，测试包同样适用。构建依赖从核心当前版本解析，编辑器交付包同时标注编辑器和核心版本。

## 修复

- 配装规范化保留包含 `/` 的合法装备 ID；无效或变化过的导入预览不能提交。
- 指挥官变更阵营后取消原支援任务；清除冷却命令正确接受带命名空间的技能 ID。
- 避免归一化直击与同发爆炸重复扣除载具血量。
- 修复动作 MOD 清除倒地卧倒、倒地状态仍可切换动作，以及拖行时旁观者看到伤员停在原地的问题。
- 修复根说明中的错误护甲版本、附属模块固定引用旧核心 JAR，以及配装编辑器附带不同内容同号核心的旧做法。
- Git 排除本地测试整合包、启动器状态和编译缓存，保留可维护源码、资源与验收记录。

## 兼容性

- 核心配装协议为 **11**，战局协议为 **18**；客户端与服务端需同步更新，不能与早期同名 0.0.1 包混用。
- 指挥官支援当前必需核心 **0.1.0+**；占点仅在启用核心联动时要求 **0.1.0+**，未安装核心时仍可独立运行。指挥官支援尚未完全脱离核心独立安装，是已记录的现有架构限制。
- 载具部位血量以 Superb Warfare 0.8.9 final 为基线，版本范围 0.8.9 至 0.9 之前；其余第三方联动按模块声明安装。
- 不变更 WOK 本体源码或 modId，不把第三方依赖 JAR 打包进源码仓库。

## 配置/存档影响

- 目录包导入会整体替换 `formations.json` 与 `loadouts.json`，先预览、再确认并自动备份；不导入玩家记录、阵营成员、当前对局或已生成载具运行状态。
- 新默认编制不会自动覆盖已有服务器配置；新伤害/移速默认值也不覆盖旧配置值。
- 车辆运输余量、小队队包冷却持续保存；重启或提高容量不会自动补满旧车。载具平衡按旧车剩余血量比例迁移，不自动修满。
- 外部 M249 与枪械平衡配置脚本不会自动变成核心内置默认配装。本次 Git 递交不替换活动游戏实例中的 MOD、配置或存档。
