# WOK 步战附属：部位血量设计基线

## 七部位

| 部位 | 默认最大血量 | 归零后果 |
|---|---:|---|
| 头部 | 35 | 立即死亡 |
| 胸部 | 85 | 立即死亡 |
| 腹部 | 70 | 高消耗；溢出伤害 ×1.5 分摊 |
| 左臂 / 右臂 | 各 60 | 挖掘与近战操作惩罚；溢出伤害 ×0.7 分摊 |
| 左腿 / 右腿 | 各 65 | 移速、跳跃惩罚；溢出伤害 ×1.0 分摊 |

## 结算顺序

1. 武器产生原始伤害。
2. WOK 护甲、原版护甲、抗性与吸收生命先处理。
3. 部位血量模组在 `LivingDamageEvent` 最低优先级读取最终净伤。
4. 净伤乘 `bodyDamageScale`（默认 10）后扣除命中部位血量。
5. 部位归零时结算死亡、失能和溢出。
6. WOK 创伤模组继续负责疼痛、流血、大出血和治疗物品。

部位血量是玩家的权威生命系统。原版红心仅作为底层死亡/不死图腾兼容载体，正常局部伤害不再扣红心。

## TaCZ 命中判定

- TaCZ 已给出的爆头标记直接对应头部。
- 非爆头根据子弹碰撞点相对玩家包围盒的高度和左右位置判定胸、腹、手臂或腿。
- 左右以受击者自身朝向为准，而不是攻击者视角。
- 爆炸伤害按头 8%、胸 25%、腹 22%、双臂各 10%、双腿各 12.5% 分散。

## 创伤联动

- 创伤药包的普通治疗转为治疗缺血比例最高的部位。
- 普通流血与大出血转为全身持续失血，可最终使头部或胸部归零。
- 镇痛、止血和震颤仍由创伤模组管理，部位血量不重复注册同类效果。

## 待护甲源码接入后校验

- 护甲 MOD 的实际 mod id 与事件优先级。
- 护甲覆盖部位（头盔、胸甲、护裆、护臂、护腿）是否能暴露命中部位 API。
- 穿甲弹是否在护甲 MOD 内完成后再进入本模组；本模组不重复计算穿透。

## 独立安装原则

所有 WOK 步战附属 MOD 都以 Minecraft 1.20.1 与 Forge 为唯一强制依赖：

| 安装组合 | 行为 |
|---|---|
| 仅部位血量 | 七部位、通用命中判定、HUD、失能和原版治疗正常工作 |
| 仅创伤治疗 | 疼痛、流血、药品和爆炸脑震荡正常工作 |
| 仅配装核心 | 配装、管理界面和服务端存档正常工作 |
| 部位血量 + 创伤治疗 | 启用部位治疗与全身流血桥接 |
| 任一战斗 MOD + TaCZ | 启用对应枪伤联动；TaCZ 缺失或接口异常不阻止核心启动 |
| 任一战斗 MOD + 护甲 | 护甲先结算，部位系统读取最终净伤 |

发布前运行 `tools/verify_mod_independence.ps1` 检查：兄弟 MOD 不得标记为
`mandatory=true`，也不得把兄弟 MOD 或 TaCZ 的类打进自身 JAR。
