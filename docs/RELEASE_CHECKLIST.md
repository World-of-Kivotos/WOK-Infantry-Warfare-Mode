## 发布说明

每次正式发布必须包含以下栏目，没有内容时写“无”：

1. 新增
2. 修改
3. 修复
4. 兼容性
5. 配置与存档影响
6. 测试结果
7. 已知问题

发布包只附带本次模块对应的 JAR，并记录 SHA-256。确认发布成功后再创建模块专属标签。
