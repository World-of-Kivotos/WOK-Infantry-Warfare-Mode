## 首次游戏内验收

1. 用 PCL 启动 `1.20.1-Forge_47.4.22`，先停在主菜单，确认没有“缺少依赖”或“重复 MOD”界面。
2. 进入专用测试存档，在主世界移动至少数个区块，让 Xaero 建立局部缓存。
3. 按 `M` 打开 WOK 战术地图，确认状态栏显示 Xaero 地形，地图能随移动和缩放更新。
4. 确认 Xaero 原生小地图被隐藏，但 `config` 中的 Xaero 设置没有被永久改写。
5. 检查 `K` 键小队/兵种/部署 UI、`L` 键配装 UI，以及 TaCZ、Superb Warfare 0.8.9、FCP、DragonRise、VVP、Create 和四个当前启用的 WOK步战模块入口。载具部位血量模块当前不参与这轮测试。
