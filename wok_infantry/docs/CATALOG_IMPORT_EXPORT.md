# 阵营与管理员配装导入导出

本功能属于 `WOK步战核心`（`wok_infantry`），需要管理员权限等级 2。普通玩家只能从管理员配置的兵种、装备池和编制白名单中选择；本功能不给玩家创建装备、提交任意物品或导入个人配装的权限。

## 数据范围

一个 UTF-8 JSON 包同时保存整个 `formations.json` 与 `loadouts.json` 的有效配置，包括：

- 全部阵营的 ID、名称、介绍、蓝红方映射、启用状态和人数限制。
- 全部编制的名称、介绍、图标资源 ID、类别、顺序、兵种名额、小队规则、能力、支援权限、部署与复活规则。
- 编制载具的实体 ID、数量对应的配置槽、生成偏移、朝向、补发间隔及其余配置字段。
- 全部兵种装备池，包含未被编制引用的装备池；槽位顺序、库存目标、必需状态、装备顺序、物品数量、完整 SNBT、逐枪弹药上限和编制白名单。

不包含玩家选择记录、阵营成员名单、当前投票、对局、出生点实例、载具实例或剩余补给。图标只保存资源 ID，物品/枪包/载具 MOD 和外部资源包本身需要另外安装。运输补给的服务端 TOML 不是阵营编制配置，不包含在此包中。

## 管理员界面

1. 按 `U` 或执行 `/loadoutadmin` 打开管理员配装终端，点击右上角“导入 / 导出”。
2. 输入文件名，点击“导出全部”。整个阵营与配装目录写入服务端的 `config/wok_infantry/catalogs/<名称>.json`；单人游戏时就是本地实例的该目录。同名文件会被拒绝覆盖。
3. 要迁移到另一台服务器，将这个 JSON 文件复制到目标服务器相同目录；无需分别搬运两个配置文件。
4. 点击“文件列表”，用 `‹` / `›` 浏览文件，也可以直接输入文件名。点击“预览导入”查看阵营、编制、兵种、槽位、装备和载具配置数量。
5. 点击红色“确认整体替换”。导入为全量替换，先自动导出当前配置为 `before-import-<UTC时间>-<随机后缀>.json`，再提交两个配置文件并刷新在线客户端。

文件名支持汉字、字母、数字、下划线、连字符和点，主体最多 64 字符，`.json` 后缀可省略；不允许文件路径或 Windows 设备保留名称。长状态信息可用滚轮查看。

## 命令

```text
/loadoutadmin export my_catalog
/loadoutadmin files
/loadoutadmin files 2
/loadoutadmin import my_catalog
/loadoutadmin import my_catalog confirm <预览返回的令牌>
```

预览返回完整确认命令；聊天中点击后填入输入框，再按回车即可。中文名称在命令中加双引号，例如 `/loadoutadmin export "学院军"`。专用服务端控制台也可执行，不需要在线玩家。`/battle admin formation export|import|files` 提供相同入口。

预览只读取和校验，不修改配置。预览有效期为 5 分钟，绑定操作者、文件名、文件内容和当前生效配置；预览后任一配置变化都必须重新预览。确认令牌只能使用一次。

## 校验、备份与恢复

- 包格式标识为 `wok_infantry_catalog`，包版本 1，阵营格式版本 2，配装格式版本 3。较新/未知版本、未知字段、字段缺失、重复 JSON 键、损坏 JSON、非法 UTF-8、重复 ID、超限数据及无效白名单引用均会被拒绝，不静默丢弃字段。
- 服务端逐件复用现有装备校验，拒绝不存在的物品、非法 SNBT、数量或弹药上限，以及不能进入步兵配装的物品。载具和支援能力继续使用现有可选 MOD 可用性规则，不删除尚未安装的载具/支援定义。
- 单包最大 8 MiB；两个配置的紧凑 JSON 总字符数最大 900000，预留现有客户端快照协议所需空间。
- 自动备份与普通导出包相同，恢复时预览并导入对应 `before-import-...json` 即可。
- 导入两个文件前保存原文件字节及事务标记。写入失败时自动恢复；进程在提交中退出时，下次加载阵营或配装前恢复原文件。`.catalog-import/ready` 存在期间常规配置保存暂停，防止覆盖恢复记录。提交后沿用阵营重载的在线成员、投票候选与载具配置调和规则；已失效的选择可能被重置，导入不重发玩家装备或补满载具补给。
- 若恢复自身因磁盘权限等原因失败，会保留恢复记录并报错；先修复存储问题，再重启完成恢复。不要手工删除仍有 `ready` 的恢复目录。

本功能从 `WOK步战核心 0.1.0` 提供。客户端和服务端必须同步更新：配装网络协议从 10 变为 11。以后新增内容必须使用新版本，详见根目录 `docs/VERSIONING.md`。
