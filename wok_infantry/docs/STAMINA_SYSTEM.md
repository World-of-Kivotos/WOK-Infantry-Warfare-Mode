# WOK步战体力系统

体力系统属于 `WOK步战核心`（modId `wok_infantry`），不属于 `WOK` 本体，也不会回灌到 `WOK-本体护甲`。首版使用服务端权威的手部/腿部双池模型，并通过可选反射边界联动 TaCZ 1.1.8+；没有安装 TaCZ 时核心仍能独立启动，腿部体力仍正常工作。

## 资源与行为

| 资源 | 最大值 | 消耗 | 默认消耗速度 | 恢复 |
|---|---:|---|---:|---:|
| 手部体力 | 100 | 主手持 TaCZ 枪械并持续开镜 | 每 tick 0.14（约 2.8/秒） | 停止消耗 0.8 秒后约 8.4/秒 |
| 腿部体力 | 100 | 实际移动中的疾跑 | 每 tick 0.40（约 8/秒） | 停止消耗 0.8 秒后约 6.8/秒 |
| 腿部体力 | 同上 | 跳跃 | 每次 10 | 同上 |

腿部降到 0 后服务端强制结束疾跑，恢复到 15 才允许再次持续疾跑。创造和旁观玩家不启用体力规则。玩家的两池数值写入自身持久化 NBT，并在登录、重生与联机过程中同步给本地客户端。

以上消耗、恢复、恢复延迟和疾跑重启阈值都在服务端配置的 `stamina` 分组中，可按整合包节奏调整；客户端不能自行降低消耗。

## TaCZ 稳定性联动

手部或腿部体力低于 35% 后开始产生枪械不稳定：

- 手部疲劳是主要来源，归零时达到完整摆动幅度。
- 腿部疲劳最多贡献 35% 摆动，用来表现刚结束冲刺时的呼吸起伏。
- 客户端每 tick 先移除上一帧由本系统施加的偏移，再叠加新的双频呼吸曲线，因此不会积累视角漂移，也不会吞掉玩家自己的鼠标输入。
- 低体力晃动同时接入 Forge 相机角度和 TaCZ 实际使用的手持渲染矩阵，避免客户端 tick 朝向被后续渲染覆盖；腰射/持枪时保留 55% 视觉影响，开镜时使用完整幅度。

TaCZ 的枪械识别与开镜状态通过 1.1.8 API 的反射边界读取。API 缺失或发生不兼容时会记录一次警告并关闭手部/TaCZ 联动，不阻止 `wok_infantry` 加载。

## HUD

左下角部位血量人体 HUD 的总血量数字下方使用一个 `52×11` 的迷你双层条：上方蓝色代表手部、下方橙色代表腿部；35% 以下转为警示橙色，15% 以下转为危险红色。迷你条不常驻显示数字，管理员需要精确值时可用 `/battle admin stamina status`。未安装部位血量 MOD 时，体力条仍独立固定在相同的左下安全区。

权限等级 2 的服主可用 `/battle admin stamina status` 查看自身当前数值，用 `/battle admin stamina set <手部0-100> <腿部0-100>` 复现疲劳状态，或用 `/battle admin stamina reset` 恢复双池。该入口用于验收和调参，普通玩家无权调用。

## 首轮游戏验收重点

1. 320×240 与 960×720 分别检查迷你双条、人体总血量、热键栏和 TaCZ HUD 是否重叠。
2. 连续疾跑约 12.5 秒应耗尽腿部体力；归零后不能靠反复按键保持疾跑。
3. 连续跳跃应每次扣除 10 点腿部体力，落地和坠落不应被误记为跳跃。
4. 持 TaCZ 枪开镜约 35 秒应耗尽手部体力；非 TaCZ 物品不消耗手部体力。
5. 35% 附近摆动应平滑淡入，松开开镜后视角不应残留偏移；刚跑停、腿部归零但手部充足时只应出现较轻呼吸摆动。
6. 双人联机确认 HUD 数值来自服务端、重新登录仍保留当前体力、创造/旁观模式不显示体力 HUD。
