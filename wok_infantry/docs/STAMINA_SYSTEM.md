# WOK步战体力系统

体力系统属于 `WOK步战核心`（modId `wok_infantry`），不属于 `WOK` 本体，也不会回灌到 `WOK-本体护甲`。首版使用服务端权威的手部/腿部双池模型，并通过可选反射边界联动 TaCZ 1.1.8+；没有安装 TaCZ 时核心仍能独立启动，腿部体力仍正常工作。

## 资源与行为

| 资源 | 最大值 | 消耗 | 默认消耗速度 | 恢复 |
|---|---:|---|---:|---:|
| 手部体力 | 100 | 主手持 TaCZ 枪械并持续开镜 | 每 tick 0.14（约 2.8/秒） | 停止消耗 3 秒后约 8.4/秒 |
| 腿部体力 | 100 | 实际移动中的疾跑 | 每 tick 0.40（约 8/秒） | 停止消耗 3 秒后约 6.8/秒 |
| 腿部体力 | 同上 | 跳跃 | 每次 10 | 同上 |

腿部降到 0 后，客户端与服务端同时结束疾跑，在原版冲刺入口移除速度加成，持续按冲刺、双击前进或重复发送冲刺请求均不能绕过。默认恢复到 15 才允许再次疾跑；锁定期间尝试冲刺不会继续消耗体力或推迟恢复。创造和旁观玩家不启用体力规则。玩家的两池数值和耗尽锁定写入自身持久化 NBT，并在登录、重生与联机过程中同步给本地客户端。

从核心 `0.2.0` 起，体力网络协议为 `2`，客户端与服务端必须同步更新。旧存档没有锁定标记时可正常读取，零体力仍自动锁定；其他模块无需随之升级版本。

以上消耗、恢复、恢复延迟和疾跑重启阈值都在服务端配置的 `stamina` 分组中，可按整合包节奏调整；客户端不能自行降低消耗。

从 `0.2.1` 起，默认 `recoveryDelayTicks = 60`（20 tick/秒，即 3 秒）。手部和腿部分别计时：再次开镜重新计算手部冷却，再次冲刺或跳跃重新计算腿部冷却；耗尽后被拒绝的冲刺尝试不会重置冷却。整个冷却期间数值不增加。重新登录或重生会重新等待完整冷却，避免运行状态重建后立刻恢复。

现有世界保留其原配置，不会仅因升级 JAR 自动改变 16 tick 的旧值。要采用本次默认值，将该世界 `serverconfig/wok_infantry-server.toml` 的 `[stamina]` 下 `recoveryDelayTicks` 改为 `60`；其他消耗与恢复速度无须改动。

## TaCZ 稳定性联动

手部或腿部体力低于 50（满值 100）后开始产生枪械不稳定；恰好 50 时不晃动，体力越低，晃动幅度越大：

- 手部疲劳是主要来源，归零时达到完整摆动幅度。
- 腿部疲劳最多贡献 35% 摆动，用来表现刚结束冲刺时的呼吸起伏。
- 强度以平滑曲线渐入：手部 40 / 25 / 10 / 0 时，疲劳系数分别约为 10.4% / 50% / 89.6% / 100%，避免跨过阈值时突然抖动。
- 客户端仅在当前帧的相机角度和持枪矩阵上叠加双频呼吸曲线，不改写玩家输入朝向，因此不会积累视角漂移，也不会吞掉玩家自己的鼠标输入。
- 低体力晃动同时接入 Forge 相机角度和 TaCZ 实际使用的手持渲染矩阵，避免客户端 tick 朝向被后续渲染覆盖；腰射/持枪时保留 55% 视觉影响，开镜时使用完整幅度。

TaCZ 的枪械识别与开镜状态通过 1.1.8 API 的反射边界读取。API 缺失或发生不兼容时会记录一次警告并关闭手部/TaCZ 联动，不阻止 `wok_infantry` 加载。

## HUD

体力条带“手/腿”标签（英文 A/L），常态为中性灰，50 以下（开始摆动）转为警示橙色，15 及以下转为危险红色；不常驻显示数字，管理员需要精确值时可用 `/battle admin stamina status`。

- 装有部位血量 MOD 且其 HUD 可见时，体力画在人体 HUD 总血量下方的 `52×11` 伴随槽里，一行显示“手 ▬ 腿 ▬”；人形与其布局归部位血量，不变。GUI 缩放 1 且启用 `ui.minimumScale2x` 时，这一行改为两条无标签细条。
- 未安装部位血量 MOD 或其 HUD 隐藏时，体力自绘左下底板（“手”在上、“腿”在下），右缘始终避开快捷栏、副手格和左侧攻击指示器；GUI 缩放 1 的 2× HUD 在原版聊天下方只放得下一行，改为同一行。
- 创造与旁观模式、按 F1 时不显示体力。

权限等级 2 的服主可用 `/battle admin stamina status` 查看自身当前数值，用 `/battle admin stamina set <手部0-100> <腿部0-100>` 复现疲劳状态，或用 `/battle admin stamina reset` 恢复双池。该入口用于验收和调参，普通玩家无权调用。

## 游戏验收重点

当前冷却实测见 [0.2.1 恢复冷却验收](STAMINA_ACCEPTANCE_0.2.1.md)，前版冲刺和晃动实测与复验命令见 [0.2.0 体力验收记录](STAMINA_ACCEPTANCE_0.2.0.md)。

1. 320×240 与 960×720 分别检查“手/腿”体力条、人体总血量、热键栏、副手格和 TaCZ HUD 是否重叠。
2. 连续疾跑约 12.5 秒应耗尽腿部体力；归零后不能靠反复按键保持疾跑。
3. 连续跳跃应每次扣除 10 点腿部体力，落地和坠落不应被误记为跳跃。
4. 持 TaCZ 枪开镜约 35 秒应耗尽手部体力；非 TaCZ 物品不消耗手部体力。
5. 50 以下摆动应平滑淡入，在 40、25、10、0 时逐渐增强；松开开镜后视角不应残留偏移。刚跑停、腿部归零但手部充足时只应出现较轻呼吸摆动。
6. 双人联机确认 HUD 数值来自服务端、重新登录仍保留当前体力、创造/旁观模式不显示体力 HUD。
