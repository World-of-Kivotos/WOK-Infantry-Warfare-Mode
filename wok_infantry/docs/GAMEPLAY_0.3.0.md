# WOK步战玩法调整 0.3.0-beta.1

本轮范围：基地十五秒补给、救起一血及失明、占点资格、兵力值、机枪渐进卧姿后坐力。
未改小箱重新部署领取规则或 M203 携弹上限。

## 基地圈地与补给

先设置蓝/红方主基地部署点，再用 `/battle basearea tool` 领取基地圈地工具。
左键选 A、右键选 B；两点形成包含边界的三维长方体，请把玩家站立高度包含在内。
`/battle basearea set blue` 或 `red` 保存，`show` 查询，`clear` 删除。
每方一个范围，必须包含对应主基地部署点，双方不能重叠，单轴跨度不超过 1024 格。
范围单独保存在世界 `data/wok_infantry_base_supply_areas.dat`；原主基地部署坐标保留。
旧球形半径不再用于补给，升级后管理员须圈定范围，未圈定不会自动补给。

正常作战且已部署的玩家进入己方范围后自动开始十五秒倒计时；可在区域内移动。
倒计时、中断与完成显示在独立战术提示面板，窄屏放在右栏以避开医疗和小队 HUD。
离区、死亡、倒地、切换生命批次或退出重连会中断并重新等待完整十五秒。
完成时保留已有物品及发放批次，只补配装物品数量和所持枪械的备用弹药缺额。
不会覆盖运输货物，不重置已有枪械附件、弹匣状态、武器调整或装备耐久。
槽位冲突和背包空间不足会显示提示；离开重进或使用原补给按钮/命令可再次启动十五秒计时。
原补给按钮/命令不再绕过等待瞬间刷新整套配装。

## 救援与占点

倒地救起后原版生命和所有身体部位分别设为绝对 1 点，不乘治疗换算倍率。
清除普通/严重出血以避免救起当帧立即死亡；移除旧版救起时赠送的三秒抗性 V。
新增失明默认五秒，可用倒地配置 `reviveBlindnessSeconds` 调整。
旧 `reviveHealth`、`bodyHealthReviveAmount` 不再参与救援；伤员需后续医疗恢复。
倒地模块仍可单独安装；与部位血量联用时需部位血量 `0.1.0-beta.1` 或更新版本。

占点排除死亡、旁观、倒地玩家；安装核心时还必须为 ACTIVE 部署状态。
不安装核心时继续支持原有独立阵营识别。核心判定本局结束后暂停占领推进。

## 兵力值

默认每方 500 点，彻底死亡或主动重新部署扣 1 点，倒地和被救起不扣。
按发放生命批次去重；已扣损失 ID 持久化，重放回调/重连不重复扣除。
兵力只由上述两种玩家损失扣除；载具损失、占点及全占据点均不扣兵力。
任一方降到零立即判负并持久保存结果；玩家回到等待区，停止部署与自动载具补充。
管理员 `/battle tickets` 查询；`/battle tickets reset` 执行统一战局重置，等同开启新局。
原战局重置也会重置兵力、占点进度，保留据点形状、顺序、时长和启用设置。

默认值保存在每个世界的 `serverconfig/wok_infantry-gameplay.toml`。
`tickets.initial` 只影响新局，重启或修改初始值不会给正在进行的对局补兵力。
`tickets.deathCost` 调整彻底死亡与主动重新部署的每次扣点数。
兵力数据在世界 `data/wok_infantry_tickets.dat`，不依赖在线人数或客户端计数。

## 机枪卧姿

TaCZ M249 和枪包类型为 `mg` / `machine_gun` 的机枪，陆地卧倒静止时逐渐稳定。
默认 40 tick（两秒）由非卧姿后坐力平滑降到原枪包卧姿倍率；M249 的原倍率为 0.1。
移动时以稳定速度的两倍失去稳定，起身、水中、离地、倒地或换枪位重置。
不修改枪包、附件缓存或持枪 NBT，不因开火引起的弹药同步不断重新计时。
`machineGun.proneSettleTicks` 可调。机枪以外的武器保留枪包原有卧姿表现。
