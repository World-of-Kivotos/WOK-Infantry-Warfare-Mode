# M249 站姿与卧姿后坐力试调

当前千禧年机动部队的 M249 采用高非卧姿后坐力：站立、蹲下时难以持续压住连射，卧倒后明显稳定。

| 参数 | 原值 | 试调值 |
| --- | ---: | ---: |
| 配装垂直后坐倍率 | 3.50 | 8.00 |
| 配装水平后坐倍率 | 3.00 | 6.00 |
| 枪包 `crawl_recoil_multiplier` | 0.10 | 0.10，沿用原值 |

同一把枪、相同附件和开镜状态下，卧姿角度后坐力是非卧姿的 10%。相对于原配置，站姿与卧姿的垂直后坐均提高约 129%，水平后坐均提高 100%；卧姿仍保留 90% 的相对减免。此数值是首轮试调，站姿是否足够猛烈、卧姿是否仍然可控需实际射击确认。

## 生效范围与兼容

- 仅修改 `config/wok_infantry/loadouts.json` 中现有 `tacz:m249` 配装的两项后坐力 NBT；本机目前只有班用机枪手的一个条目。
- TaCZ 1.1.8 在玩家处于非水中 `SWIMMING` 姿态时应用枪包的卧姿倍率。普通潜行蹲下仍使用高后坐力；moveslikemafuyu 的陆地爬行使用该卧姿机制。
- 当前两脚架附件提供常驻的垂直 ×0.8、水平 ×0.7 修正，无需架设。卧姿减免来自枪包，与两脚架是否安装无关；本次没有新增架设系统。
- 开镜速度、伤害、穿甲、射速、散布、附件、载弹量、备用弹药上限和其他枪械均保留。
- 不修改第三方枪包或既有发布包。这是外部服务器配装调整，脚本归档于核心 0.1.0 的配套工具；它不会自动写入核心 JAR 的默认配装。以后交付修改后的配置包须另记配置包版本与适用核心版本。新加入的其他机枪需按各自原始后坐曲线另行调试。

## 应用

先退出测试世界或停止服务器，再使用 Python 3 运行 `tools/apply_m249_stance_recoil.py`，默认仅预览；添加 `--apply` 才写入。默认目标是 WOK步战专用测试实例，可用 `--test-root` 指定其他明确的测试副本。脚本先确认当前 M249 枪包的卧姿倍率为 0.1，再核对改动仅涉及目标 NBT，自动备份原文件并替换配置；重复应用不会继续放大倍率。

当前没有配装配置重载命令，`formation reload` 仅重载编制；运行中的配装服务退出时还会保存内存配置，可能覆盖外部修改。应用后重新进入世界或重启服务器，并重新部署领取 M249，或在己方主基地使用 `/battle deployment resupply`（需要已部署且补给冷却结束）重新领取。已有背包中的枪保留原 NBT。

## 验收

配置验证应确认仅两项后坐力 NBT 改变、其余 JSON 内容完全一致；再次应用不产生改动，卧姿倍率异常时应拒绝写入。

游戏内在同一位置、相同体力和开镜档位下，分别站立、蹲下、卧倒，对 25 格与 75 格固定目标进行 3–5 发点射及 20 发连射。站立和蹲下应明显难以持续压枪，卧倒应明显改善；起身后立即恢复高后坐力。最后拆下两脚架复查卧姿仍有效，并确认水中不会取得陆地卧姿减免。

副本验证已通过：仅两个数值变化、备份逐字节一致、重复应用不产生变化、卧姿倍率不符时拒绝写入。已在无 Java 进程运行时应用到专用测试实例，并完成同等差异校验。本轮游戏内手感尚未验收。
