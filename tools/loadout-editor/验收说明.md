# WOK步战编制配装编辑器 · 测试交付说明

日期：2026-09-06。类型：离线工具 `0.1.0-beta.1` 与配套核心 `0.1.0`；采用独立版本，不再交付不同内容的同号核心。

## 新增

- 单文件离线 HTML 工作台，采用现有战术平板主题的配色、机械框与按钮状态。
- 阵营、编制、兵种、装备槽位、可选装备、白名单、小队名额、载具位置／补充、支援及部署策略编辑。
- 独立复制编制与装备池、成品配装库、枪械库、配件、逐枪备弹和 7 项属性倍率。
- 工程保存与恢复、完整游戏数据包导出、基线三方合并、冲突报告、撤销与本地草稿。

## 修改

- 阵营文档交付规则增加离线工程文件流程。游戏 catalog 格式沿用现有实现，无格式变更。
- 附带已构建的 WOK步战核心 `wok_infantry-0.1.0.jar`，提供游戏端数据包入口；目录和 ZIP 名称包含编辑器与核心版本，新增 `VERSION.json`。

## 修复

- 工程输入先检查完整树结构，防止损坏文件替换当前工作状态；文本显示转义。
- 撤销合并同时恢复基线与来源；添加装备仅更新当前编制非空白名单。
- 避免删除最后一个受限装备时意外放开白名单；可显式整理失效引用。
- 窄屏不产生页面横向溢出，表单高级区域在修改后保持展开状态。

## 兼容性

- 游戏数据包：`wok_infantry_catalog` v1，formations v2，loadouts v3。
- 离线编辑器使用现代 Edge／Chrome。浏览器检查中使用本机 Edge 无头模式，无外部网络资源。
- 配套核心为 Minecraft 1.20.1 / Forge 47 / Java 17。枪械、配件和载具资源取自本次测试环境；目标环境仍需安装对应内容。
- 原测试实例核心尚无 catalog 导入功能，需按安装说明替换为兼容核心。当前实际游戏文件未修改。

## 配置／存档影响

- 网页打开、编辑、保存仅操作浏览器副本及下载文件。
- 工程文件包含原始基线和当前修改；未知字段保留为草稿，但游戏不接受的字段会阻止数据包导出。
- 游戏端确认导入会整体替换阵营与配装，自动备份原配置；玩家记录保留。删除编制／小队／载具、调整容量仍可能触发游戏状态调和。
- 随包演示目录只有两套编制，明确开放其实际装备选项，用于学习；不得当作当前服务器完整配置直接替换。旧测试配置中的无效引用未被自动改写。

## 测试结果

- 25 项 Node 单元测试全部通过：目录往返、引用与字段限制、独立复制、三方合并与冲突、结构损坏拦截、SNBT 无损编辑与错误输入。
- 浏览器完整流程通过：打开离线 HTML、调整倍率与备弹、复制编制、选择成品和新枪、工程保存／重开、JSON 下载、损坏输入拒绝、合并／撤销／再合并及全部页面。
- 浏览器视觉检查：1440×1000、960×720、320×240；无页面横向溢出，关键操作可访问。另检查小屏帮助弹窗。
- 使用配套生产 JAR 的 `CatalogArchive.decode` 实际解析通过：浏览器导出包为 2 阵营／3 编制／16 兵种；演示目录为 2 阵营／2 编制／10 兵种。验证覆盖游戏严格格式、规范化及引用完整性。
- **未执行**：真实游戏启动后的完整导入、物品发放、配件兼容、开火实测、载具位置验收与存档回归。解析通过不代替这些游戏内验证。
